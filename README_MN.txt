ИХ ЗАСАГ ЧИНГИС СООСЭ ПОЛИТЕХНИК КОЛЛЕЖ
ӨМНӨХ САЙТ + SQLITE + АДМИН САМБАР

ЮУ БАЙГАА ВЭ?
- Өмнөх index.html болон program-details.html хадгалагдсан.
- SQLite өгөгдлийн сан зөвхөн “Мэргэжлүүд” dropdown-ийн мэдээллийг өгнө.
- /admin гэсэн тусдаа, нэвтрэх хамгаалалттай админ самбар нэмсэн.
- Админ самбараас мэргэжил нэмэх, нэр/slug/эрэмбэ өөрчлөх, идэвхтэй эсэхийг тохируулах, устгах боломжтой.
- Google Form болон сайтын бусад хэсгийг зориуд өөрчлөөгүй.

WINDOWS ДЭЭР АЛХАМ АЛХМААР
1. ZIP дээр right-click -> Extract All... -> Extract.
2. ikh_zasag_sqlite_project хавтас руу ор.
3. .env.example файлын хуулбарыг үүсгээд нэрийг нь яг .env болго. Windows өргөтгөлийг нууж байвал File Explorer -> View -> Show -> File name extensions-ийг асаа.
4. .env файлыг Notepad-аар нээ. ADMIN_USERNAME болон ADMIN_PASSWORD-ийг өөрийнхөөрөө солино. SECRET_KEY дээр урт, таахад хэцүү нууц мөр бич. Жишээ нууц үгийг хэвээр нь үлдээж болохгүй.
5. Хавтасны дээд address bar дээр cmd гэж бичээд Enter дар.
6. Командуудыг нэг нэгээр нь ажиллуул:
   py --version
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   py app.py
7. Chrome дээр http://127.0.0.1:5000 гэж нээ. Энэ нь үндсэн сайт.
8. Админ самбар: http://127.0.0.1:5000/admin
9. .env файлд бичсэн ADMIN_USERNAME болон ADMIN_PASSWORD-өөр нэвтэр.
10. Ажил дуусах хүртэл хар Command Prompt цонхыг хааж болохгүй. Зогсоохдоо Ctrl+C дар.

АДМИН САМБАРТ ЮУ ХИЙЖ БОЛОХ ВЭ?
- Нэр болон slug-аар мэргэжил нэмэх.
- Мэргэжлийн нэр, slug, эрэмбийг засах.
- Идэвхтэй тэмдэглэгээг болиулж цэснээс нуух/дахин харуулах.
- Мэргэжлийг өгөгдлийн сангаас устгах.

ЧУХАЛ
- SQLite файлыг анх ажиллахад programs.db нэрээр үүсгэнэ.
- Админд шинээр мэргэжил нэмэхэд dropdown-д гарна. Гэхдээ дэлгэрэнгүй танилцуулгын текст/зураг нь program-details.html дотор тусдаа жагсаалт тул шинэ мэргэжлийн дэлгэрэнгүй хуудсыг тэр файлд нэмэх хэрэгтэй.
- Админ самбар нь энэ төслийн локал хөгжүүлэлтийн хувилбар. Интернэтэд нийтлэхийн өмнө HTTPS, хүчтэй нууц үг, тогтвортой SECRET_KEY, production сервер болон нөөцлөлт тохируул.
- .env файлыг бусдад явуулахгүй, нийтийн Git репозиторт оруулахгүй.
- Салбар дээр бодитоор сургалт явуулдаг мэргэжлүүдийн жагсаалтыг нийтлэхээс өмнө сургуулиас баталгаажуул.

АЛДАА ГАРВАЛ
- “py is not recognized”: Python 3 суулгах шаардлагатай.
- “No module named flask” эсвэл dotenv: .venv\Scripts\activate, дараа нь pip install -r requirements.txt.
- Admin нэвтрэх тохиргоо байхгүй: .env файл байгаа, ADMIN_PASSWORD бөглөгдсөн эсэхийг шалга.
- Цэс шинэчлэгдэхгүй: index.html-ийг давхар дарж нээхгүй; http://127.0.0.1:5000 ашигла.
